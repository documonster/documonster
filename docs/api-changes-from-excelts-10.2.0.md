# Type changes from excelts 10.2.0

Every name `@cj-tech-master/excelts` 10.2.0 and `documonster` both publish whose type differs, generated by `pnpm verify:excelts-guide --write` from the two packages' declarations. A name that moved or was renamed is not here — [the migration guide](../MIGRATION_EXCELTS_TO_DOCUMONSTER.md) says where it went; this file is for the names that stayed and changed underneath. Differences that are only printing (a union in another order, a type printed under another of its names) are left out, as in [the release diff](api-changes-since-v0.21.1.md).

## Byte results narrowed to `Uint8Array<ArrayBuffer>`

These names changed only in that a `Uint8Array<ArrayBufferLike>` they returned or yielded is now a `Uint8Array<ArrayBuffer>` — a plain array over a plain `ArrayBuffer`, never a `Buffer` or a view of a `SharedArrayBuffer`. It is assignable everywhere the old type was, so code that compiled keeps compiling.
